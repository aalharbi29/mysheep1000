

## خطة: التحكم في أبعاد الشعار (عرض × ارتفاع) لكل موقع بشكل مستقل

### المشكلة
حالياً أحجام الشعارات ثابتة في الكود ولا يمكن تعديلها من الإعدادات. المطلوب التحكم في العرض والارتفاع بالبكسل لكل شعار على حدة (شاشة البداية، صفحة الدخول، الصفحة الرئيسية) مع معاينة مباشرة.

### الخطوات

**1. تحديث قاعدة البيانات** — إضافة 6 أعمدة جديدة لجدول `splash_settings`:
- `splash_logo_width` / `splash_logo_height` (شاشة البداية) — افتراضي 192×192
- `auth_logo_width` / `auth_logo_height` (صفحة الدخول) — افتراضي 192×128
- `dashboard_logo_width` / `dashboard_logo_height` (الصفحة الرئيسية) — افتراضي 64×64

**2. تحديث `splashSettings.ts`** — إضافة الحقول الجديدة إلى `SplashSettings` interface و`defaultSplashSettings` ودوال التحويل.

**3. تحديث `SplashSettingsCard.tsx`** — إضافة قسم جديد بعنوان "أبعاد الشعار" يحتوي على:
- 3 مجموعات (شاشة البداية / صفحة الدخول / الرئيسية)
- كل مجموعة: slider للعرض (40-400px) + slider للارتفاع (40-400px)
- معاينة مباشرة لكل شعار بالأبعاد المحددة

**4. تحديث الصفحات** لاستخدام الأبعاد من الإعدادات:
- `SplashScreen.tsx` — استخدام `splashLogoWidth/Height`
- `AuthPage.tsx` — استخدام `authLogoWidth/Height`
- `Dashboard.tsx` — استخدام `dashboardLogoWidth/Height`

### التفاصيل التقنية
- Migration SQL يضيف 6 أعمدة integer بقيم افتراضية
- الأبعاد تُطبق عبر inline style (`width`/`height` بالبكسل) مع `object-contain`
- المعاينة في الإعدادات تعرض الشعار الفعلي بالأبعاد المختارة فوراً
