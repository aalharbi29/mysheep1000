

# خطة إضافة قسم السوق

## نظرة عامة
إضافة بطاقة "السوق" في الصفحة الرئيسية تفتح نظام متعدد الطبقات للبيع والشراء، مع معالج خطوات لبيع الغنم يشمل اختيار النوع والسلالة والتفاصيل ورفع الوسائط.

## التغييرات المطلوبة

### 1. قاعدة البيانات
- إنشاء جدول `market_listings` لتخزين إعلانات السوق (النوع، الفئة، السلالة، الجنس، العدد، الحالة، الموقع، رقم التواصل، السعر، الصور/الفيديو، user_id)
- إنشاء Storage bucket باسم `market-media` لرفع الصور والفيديوهات
- إضافة سياسات RLS للجدول والتخزين

### 2. الصفحات الجديدة

| الصفحة | المسار | الوصف |
|--------|--------|-------|
| `MarketPage` | `/market` | بطاقتين: بيع / شراء |
| `MarketSellPage` | `/market/sell` | 3 بطاقات: بيع غنم، بيع سيارة، بيع منقولات |
| `MarketBuyPage` | `/market/buy` | عرض الإعلانات المتاحة |
| `SellLivestockPage` | `/market/sell/livestock` | معالج خطوات لبيع الغنم |

### 3. معالج بيع الغنم - الخطوات
1. **النوع**: ضأن / ماعز
2. **السلالة**: حسب النوع المختار
   - ضأن: حري، نجدي، نعيمي، سواكني، رفيدي، حبصي، عرب، مهجن
   - ماعز: عارضي، شامي، حجازي، هولندي، بيشي، محايلية، قبرصية، مصرية
3. **الجنس**: ذكر / أنثى
4. **التفاصيل**: العدد، الحالة (مضاريع/دفيع/ولد/حيل)، عدد البهم وعمره، عدد الفحول، أسنان الحلال، الموقع، رقم التواصل، الحد (اختياري)
5. **الوسائط**: رفع صور وفيديو من الملفات أو الكاميرا مباشرة (بجودة عالية بدون ضغط)

### 4. تحديث الملفات القائمة
- **Dashboard.tsx**: إضافة بطاقة "السوق" بأيقونة `Store`
- **App.tsx**: إضافة المسارات الجديدة

### 5. التفاصيل التقنية
- رفع الوسائط باستخدام Storage API مع `accept="image/*,video/*"` و `capture="environment"` للكاميرا
- الصور تُرفع بجودتها الأصلية (بدون ضغط) حسب طلب المستخدم
- كل إعلان يُربط بـ `user_id` مع RLS
